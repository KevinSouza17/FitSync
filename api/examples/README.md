# Exemplos de uso

Cada arquivo aqui mostra um exemplo de requisição (curl) e a resposta
esperada para uma rota da API.

- `notify-message.sh` — exemplo de chamada para `notify-message`
- `send-invite.sh` — exemplo de chamada para `send-invite`
- `stripe-checkout.sh` — exemplo de chamada para `stripe-checkout`
- `stripe-webhook.sh` — exemplo de chamada para `stripe-webhook`

Substitua `<TOKEN>` pelo JWT de sessão do Supabase e `<base_url>` pela
URL base das funções.
